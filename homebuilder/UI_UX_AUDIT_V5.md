# SMA Builders UI/UX Audit — V5

## Fixed in V5
- Desktop/laptop navigation now uses the full navigation bar at widths 992px and above.
- Hamburger/Menu button is hidden on desktop and shown only below 992px.
- Mobile hamburger uses a self-contained CSS icon; no Font Awesome dependency is required.
- Mobile navigation collapses/expands using Bootstrap's existing collapse behavior.
- Mobile dropdown menus are readable and contained within the navigation panel.
- Laptop/tablet navigation spacing is tightened to prevent unnecessary wrapping.
- Focus-visible outlines were added for keyboard accessibility.
- Template demo imagery was replaced with custom SMA Builders placeholder imagery.
- Replaced the broken `images/Before` reference.
- Added consistent image sizing and alt-text treatment.

## Placeholder image policy
All current project/hero imagery is explicitly labeled as placeholder artwork. Replace these with genuine SMA Builders project photography before production launch.
